# Gasm (Garter Assembler)

A single dialect assembler for cross-assembly
between x86, ARM, RISC, and other platforms;
Gasm aims to be a powerful piece of kit
for any bootstrapping or cross-compilation toolchains.

Gasm aims to simultaneously be closer to one-to-one machine code
than many other assembly dialects,
while aso little easier to read and a lot easier to reason about.
Keywords correspond to one _and only one_ instruction,
and the whole assembler is written in such a way that it should be trivial to port.

# Syntax and Notes

- Preprocessor directives must be on their own line, at the start
- Elsewise, whitespace is completely ignored
- Strings separated only by whitespace are contatenated
- Multiple label definitions may follow eachother and have the same value
- There is no concept of "scope" or locality excepting `global` names
- All two-letter names are reserved

```asm
#include "syscalls.asm"
#include "print.asm"

section ro				; Tabs and formatting are optional
	hello byte "Hello, world!\n\0"
	hello_end

section rx				; rx for "Readable+Executable"
origin 0xc700			; there be dragons in my bootloader
entry main
	set r0 		hello
	set r1 		(hello_end - hello)
	call 		print
	set r0 		SYS_EXIT
	set r1		0	
	syscall
```

The assembler knows many aliases for registers,
section names, and the likes.
It prefers numbered names for registers,
and whole-word mnemonic names for operations.
General Purpose registers `r0` `r1` `r2` and `r3`
may also be called `ar` `br` `cr` and `dr`, as an example.
It also names the target platform's syscall registers `s0` to `s3`,
registers for floating point maths `f0` to `f3`,
the stack pointer and base pointers `sp` and `bp`,
and many more useful bits which get mapped to their platform-specific equivalents.

# Usage

The primary, intended use for Gasm
is for assembling files generated by a compiler,
acting as its cross-assembly backend.

```sh
gasm -o ~/bin/org org.asm -t x86_64-linux
```

It will also support transpilation to
[Netwide](https://www.nasm.us/) and
[Flat Assembler](https://flatassembler.net/),
with generic Object File backend a possible future addition
to allow linking with programs like GCC

```sh
gasm -t nasm org.asm org.nasm
gasm -t obj org.asm org.o
```
